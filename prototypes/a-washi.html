Geography of Origami – A Brief Introduction to the Edge-River Method

Recently I had been discussing my edge-river method (ERM) with several folders on Discord and received fairly good responses. I will assume that the readers are considerably familiar with the tree method (developed by Lang and Meguro, etc.).

Overview

To put it simply, ERM is a generalization of the tree method to any origami design, let it be uniaxial or not. Roughly speaking, the tree method can be thought of as a design process consisting of the following steps:

  1. Represent the target subject as a tree figure.
  2. Solve the circle/river packing problem to decide the correspondence between regions on the sheet and components on the tree.
  3. Construct a flat-foldable crease pattern for the packing, so that the sheet collapses to a base resembling the tree.1

For a grid of size n \times n, each flap of length \ell consumes a river of width w = \ell / \sqrt{2}, so that the total area satisfies

\sum_{i} \pi r_i^2 + \sum_{j} w_j L_j \le n^2

An abstraction can be viewed as the specification given by the designer for the desired shape of the folded base.

Implementation

Press Ctrl + Z to undo. In Orihime, the core loop looks like this:

// Fold every crease that lies on the current layer
for (LineSegment s : creases) {
	if (s.getColor() == LineColor.RED_1) {
		folder.fold(s, "mountain");
	}
}
